# Plant Tracker illustrative 3D site model

The complete pre-arranged industrial site scene is loaded by `../3d-view.html` from:
https://cdn.3dassets.dev/assets/13465/v1/model.glb

Source pack: https://3dassets.dev/packs/ore-processing-and-haulage-plant
Licence: CC0 1.0 Universal (as stated by the publisher).
Model: one GLB starter scene containing the pack's components.

The GLB is streamed from the publisher's CDN; it is not physically included in this GitHub ZIP. The viewer therefore requires internet access and the publisher's CDN to remain available. To self-host later, download the starter scene from the source page and save it here as `plant-site.glb`, then change the `src` in `3d-view.html` to `assets/3d/plant-site.glb`.

This is a generic illustrative ore-processing/haulage facility, not a surveyed model or scan of the Angul plant.
