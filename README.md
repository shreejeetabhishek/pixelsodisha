# Steel Plant Tracker - Complete Offline Prototype

This package contains the fully functional, responsive HTML prototype along with your extracted real-world steel plant flow diagram.

## Instructions:
1. Extract ALL contents of this ZIP file into the same folder on your computer or phone.
2. Ensure `index.html` and `diagram.jpg` are in the same folder.
3. Double-click the `index.html` file to open it in any standard web browser (Chrome, Safari, Firefox).
4. The map will now display your actual steel plant process flow diagram, fully zoomable and pannable.
5. Use the control panel to add workers. Notice how the badges populate directly over the diagram!
